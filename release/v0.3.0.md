# v0.3.0

Release date: 2026-08-30

## New Features

### Facade-agnostic macros now work under the slog facade

The facade-agnostic macros (`rolling_logger::info!` / `debug!` / `warn!` /
`error!` / `trace!`) now also work under the `slog-backend` facade, not just
`tracing` and `log`.

This is achieved by registering a global slog `Logger` during `init_slog_logger`
and having the macros auto-inject it, so callers can use the same
positional-argument syntax (`info!("msg {}", x)`) across all three facades without
passing a logger explicitly:

```rust
// Under slog-backend:
let _guard = rolling_logger::init(&config)?;
rolling_logger::info!("hello {}", "world");   // no explicit logger needed
```

The structured key-value syntax specific to slog (`slog::info!(log, "msg"; "k" => v)`)
still requires slog's native macros.

## Implementation Notes

- Added `GLOBAL_SLOG_LOGGER` (`OnceLock<slog::Logger>`) in `slog_layer.rs`,
  registered by `init_slog_logger`, with a discard fallback before initialization.
- Added `global_slog_logger()` accessor, re-exported under `#[doc(hidden)]`.
- Re-exported the `slog` crate (`pub use slog`) so the facade macros can reference
  `$crate::slog::info!` etc. under macro hygiene — callers need no direct `slog`
  dependency.
- Added `slog-backend` branches to all five facade macros in `facade.rs`.
