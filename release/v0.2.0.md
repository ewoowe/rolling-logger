# v0.2.0

Release date: 2026-08-30

## New Features

### 1. Multi-facade support (core change)

Expanded from a single `tracing` facade to the three mainstream logging facades,
selectable via mutually exclusive features:

| feature | facade | notes |
| --- | --- | --- |
| `tracing` (default) | `tracing` | built on `tracing-subscriber` + `tracing-appender` |
| `log-backend` | `log` | implements `log::Log`, global singleton |
| `slog-backend` | `slog` | implements `slog::Drain`, structured key-values |

### 2. Unified initialization entry `init()`

A single API regardless of the facade:

```rust
let guard = rolling_logger::init(&config)?;
```

### 3. Facade-agnostic logging macros

Five macros — `trace!` / `debug!` / `info!` / `warn!` / `error!` — that proxy to
the enabled facade automatically, so business code stays unchanged when switching
facades.

### 4. Structured key-value serialization for slog

slog key-values are fully serialized to `key=value` text (string values quoted).

### 5. Console + file dual output (log/slog facades)

The `log` and `slog` facades gained colored console output (ANSI), while files
stay plain text — matching the `tracing` facade.

## Improvements

### 6. Unified graceful shutdown

All three low-level primitives (`init_logger` / `init_log_logger` /
`init_slog_logger`) now return `LoggerGuard`, which shuts down archiver threads
on drop.

### 7. Simplified conditional compilation

Facade branches use a single `#[cfg(feature = "...")]`; the mutual-exclusion
constraint is centralized in top-level `compile_error!` guards.

### 8. Full English documentation

Code comments, log messages, and the README are now in English. A Chinese
translation is preserved at `README.zh-CN.md`.

## Breaking Changes

- `init_logger()` return type changed from `LoggerGuards` to `LoggerGuard`.
- `LoggerGuards` is no longer public (downgraded to `pub(crate)`).
- Added the unified entry `init()`, recommended over calling the low-level
  primitives directly.
- `init_slog_logger()` return type changed from `slog::Logger` to `LoggerGuard`
  (obtain the logger via `LoggerGuard::logger()`).

## Other

- Added `rust-analyzer.toml` to pin static analysis to the `tracing` feature
  (avoids IDE false positives from mutually exclusive features).
- Ignored the `.codebuddy/` directory.
- Added a GitHub Actions CI workflow.
